## Customer App

App name:

- Arabic: مشوار
- English: Mishwar

Short description:

- Arabic: اطلب مشوارك، تابع الرحلة، وادفع بالطريقة المتاحة حسب تفعيل الخدمة.
- English: Request rides, track trip status, and use enabled payment options.

Full description:

مشوار تطبيق تنقل مخصص لطلب الرحلات داخل نطاق التشغيل المعتمد. يمكن للعميل اختيار نقطة الانطلاق والوجهة، تحديد نوع المركبة، متابعة حالة الرحلة، رؤية موقع الكابتن أثناء الرحلة عند توفره، واستخدام طرق الدفع المفعلة مثل النقد أو المحفظة أو مزود الدفع الرقمي عند تفعيله.

Main features:

- طلب مشوار.
- اختيار موقع الانطلاق والوجهة.
- اختيار نوع المركبة وعدد الركاب وخيار المكيف عند توفره.
- متابعة حالة الرحلة.
- تتبع موقع الكابتن أثناء الرحلة عند توفره.
- عرض حالة الدفع.
- طلب استرجاع عند توفر شروط الاسترجاع.

## Driver App

App name:

- Arabic: مشوار كابتن
- English: Mishwar Driver

Short description:

- Arabic: استقبل الطلبات، شارك موقعك أثناء الرحلة، وتابع أرباحك وطلبات السحب.
- English: Receive ride requests, share trip location, and track earnings and payouts.

Full description:

مشوار كابتن تطبيق مخصص للكباتن المعتمدين. يدعم استقبال طلبات الرحلات، قبول أو رفض الطلب، تحديث حالة الوصول وبدء وإنهاء الرحلة، مشاركة الموقع أثناء الرحلة، تأكيد الدفع النقدي، متابعة الأرباح، وطلب السحب حسب تفعيل النظام المالي.

Main features:

- استقبال طلبات المشاوير.
- قبول أو رفض الطلب.
- تحديث حالة الرحلة.
- مشاركة موقع المركبة أثناء الرحلة.
- تأكيد استلام النقد.
- عرض الأرباح والحركات المالية.
- طلب السحب عند توفر رصيد متاح.
- إرسال مستندات KYC كرابط عند التفعيل.

Support placeholders:

- SUPPORT_URL
- CONTACT_EMAIL
- PRIVACY_POLICY_URL
- TERMS_URL
